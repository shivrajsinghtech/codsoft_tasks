# Final Evaluation Report – Movie Genre Classification

All numbers below were produced by `python train.py` on the provided dataset
(`reports/metrics.json` holds the raw values). The full run takes about 10 minutes on 4 CPU cores.

## 1. Protocol

| Step | Data used |
|---|---|
| Hyper-parameter tuning and model selection | `train_data.txt` → stratified 80 / 20 split (43,371 train / 10,843 validation, `random_state=42`) |
| Selection criterion | **Validation macro-F1** (tie-break: accuracy). Rare genres count as much as frequent ones. |
| Final model | Selected configuration refit on all 54,214 training records |
| Predictions | `test_data.txt` (unlabelled, 54,200 movies) → `reports/test_predictions.csv` (generated by `train.py`, not committed) |
| Final evaluation | `test_data_solution.txt`, loaded **once**, after the model was selected and saved |

The TF-IDF vectoriser is fitted only on the training portion during tuning and lives inside the saved
`sklearn.pipeline.Pipeline`. Word2Vec is trained inside the pipeline's `fit`. Test labels were never
used for training, feature selection or tuning.

**Selected model on test:** accuracy **59.16 %**, macro-F1 **0.4236**, weighted-F1 **0.5931**,
**top-3 accuracy 84.91 %** (the true genre is among the three suggestions shown in the app).

Validation and test results agree closely (difference < 0.01 in every metric), so the validation
split was a reliable guide for selection.

## 3. Trade-off: accuracy vs. rare genres

The classes are heavily imbalanced: drama has 13,613 movies and war has 132, a ratio of about 103 to 1.

* The **Linear SVM** without class weights has the best accuracy (62.2 %) and macro precision. It gets
  there mostly by favouring the large classes.
* **Logistic Regression with `class_weight="balanced"`** gives up about 3 accuracy points but raises
  macro recall from 0.37 to 0.44, so rare genres such as war, sport, music and sci-fi are found far more often.
  It has the best macro-F1 on both validation and test, which matches the stated selection goal.
* For Logistic Regression, the balanced variant improved validation macro-F1 at every C
  (0.244 → 0.394 at C=1, 0.334 → 0.422 at C=5, 0.366 → 0.417 at C=20).
* For Naive Bayes, `fit_prior=False` (uniform class priors) together with a small alpha helped rare genres the most.

If raw accuracy were the only goal, the SVM would be the better choice. Both trade-offs are documented here.

## 4. Per-genre results (selected model, test set)

See `per_genre_metrics_test.csv` and `figures/per_genre_metrics_test.png`.

* **Strong:** western (F1 0.86), documentary (0.76), game-show (0.73), horror (0.65), drama (0.63), comedy (0.60).
* **Weak:** biography (0.04), history (0.11), mystery (0.19), fantasy (0.20), crime (0.24).
  The confusion matrix shows why. Biography and history plots are mostly predicted as *documentary*
  (47 % and 51 %), mystery and crime are split between *thriller* and *drama*, and romance leaks into
  *drama* (33 %). These genres overlap in vocabulary, and each IMDb title carries only one label here.

## 6. Limitations

* Single-label data for movies that are often multi-genre puts a ceiling on achievable accuracy.
* The dataset has 128 repeated descriptions under different titles. Fifteen of them carry
  conflicting genres. They were kept because they are genuine records.
* Non-Latin text is reduced to ASCII during cleaning, so a few non-English plots lose information.
